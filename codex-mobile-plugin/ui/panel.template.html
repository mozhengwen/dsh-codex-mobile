连接手机 App

手机和电脑连接互联网即可。

  1. 安装手机版
    使用本机交付的 DSH-Mobile-0.7.0.apk。
  2. 扫描左侧配对二维码
    或选择“添加连接 → Codex”，填写地址和配对码。
  3. 继续处理桌面任务
    选择现有任务，或选择工作区后新建任务。
